# Writes whose failure netcfgd deliberately does not act on.
#
# One line each: `path::function -- what its loss costs`. Enforced by
# tool/write_gate.py, which refuses any other silent write, and refuses an
# entry here that is no longer silent.
#
# **Being on this list is not permission to say nothing.** Every entry below
# reports its failure to the journal and then carries on; what makes it
# best-effort is that it does not fail the apply. A record that could not be
# kept must not turn a working configuration into a refusal -- but the
# operator is told, because the consequence arrives much later and looks
# like netcfgd having no opinion. Decision 0180.
#
# Removals are exempt by rule and are not listed: `remove_file` is asked for
# a state, and the usual error is that the state already held.

# **Empty, and that is the finding rather than the default.** When this gate
# was written there were four: the supplicant's network fingerprint, the two
# WireGuard digests and openvpn's record of the `.ovpn` it started from. Each
# was a considered decision -- none of them should fail an apply -- and each
# was also completely silent. They now say what could not be written and what
# that costs, and carry on, so none of them needs an entry here.
#
# A line will be needed the day a write genuinely must be dropped without a
# word. Nothing in the tree is that today.
