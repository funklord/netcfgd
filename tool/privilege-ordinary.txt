# Config keys reviewed and found ordinary -- safe for a client that is not
# root to send, under decision 0127.
#
# This file is an acknowledgement, not a permission list. Nothing reads it at
# run time; `privilege.rs` decides what is privileged and everything else is
# ordinary by construction. What this exists for is the gap that leaves: a key
# added to the compiler later would be ordinary because nobody looked at it.
# `tool/privilege_gate.py` refuses a key that is in neither this file nor
# PRIVILEGED, so adding one costs somebody a decision.
#
# Review it as a list of things a desktop user may set on this machine's
# network. The question for each is not "is this sensitive" but "does this
# grant more than configuring the network" -- a wifi passphrase is sensitive
# and ordinary; `tun { owner }` is neither sensitive nor ordinary, because it
# hands a device to somebody.
#
# Keys that are privileged in ANY block are absent here and live in
# PRIVILEGED instead, even where the same word is ordinary elsewhere:
# `config` is an addressing list in an interface and an .ovpn path in an
# openvpn block, and the gate matches on the name. `privilege.rs` keeps the
# block-sensitive answer; this file keeps the coverage.
#
# `exec` is here and is not a config key at all: it is a secret provider name
# that the extractor picks up from a neighbouring match. Over-inclusion is the
# safe direction for a coverage gate -- it asks for a decision that was not
# needed -- and the provider itself is caught at the value level by
# `secret_exec`, not by any key.

# The modem block (0150). An APN names a network to attach to and a SIM source
# names which card the board should present -- provisioning data, and neither
# can name a path, a command or a principal, which is the line this file draws.
#
# `sim` reaches a `pre_up` hook as a value, and that is not the same as
# granting one: the hook is already installed and installing one is privileged
# on its own. What this chooses is which source a hook that exists is told to
# select. Both are refused outright if they contain a quote, a backslash or a
# control character, since the APN is interpolated into a quoted AT command.
apn
sim
